# Small Office Network Threat Simulation

This Python script simulates a basic small office network and demonstrates how easily common devices can be compromised due to inherent vulnerabilities. It highlights the risk by showing random attack attempts with varying success rates based on device vulnerability.

## Language

`python`

## How to Run

Run this script using Python 3: `python main.py`
Press Ctrl+C to stop the simulation.
